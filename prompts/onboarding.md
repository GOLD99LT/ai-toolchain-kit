# 新人从自己的任务选择工具

把下面的提示词复制给正在使用的 AI 即可。可以先说一个困扰，也可以补充自己的系统、客户端和预算；不用先安装技能、填写 JSON、运行测试或自研安装器。作者的工作组合仅供参考，你可以只选其中一项，也可以全部不选。

## 可复制的访谈提示词

```text
请用简体中文帮我选择适合自己的 AI 工具箱。我想先改善的任务是：<填一个最常做或最费时间的任务>。

先沿用我已经告诉你的信息，只问会改变选择的缺项，每次最多三个简短问题，允许我回答“不确定”。请了解：
- 我的输入是什么、想得到什么输出，目前最费时间的是哪一步；
- 使用什么系统和客户端，哪些客户端必须都能用；
- 已经有什么工具和账号，能接受多少费用与维护工作；
- 哪些内容需要留在本地，有没有模板、编码或运行环境限制。

先阅读本仓库 catalog/README.md 和相关中文使用卡，复用已有能力。需要新工具时，只给少量有明确增益的候选，说明取舍与未确认条件。研究有日期和局限；过时或没有证据的地方明确说明，不凭关注量做质量保证。

请先给我一张“任务—推荐工具—为什么适合—现有/候选状态—费用类别—入口”的表，让我自己选择。没有合适候选可以继续使用原来的方法，不为了凑齐工具箱安装整套软件。

我选择后，给我一个公开页面或合成资料的短例，说明输入、输出位置、成功与失败信号、更新与停用入口。普通 Skills/MCP/提示词优先 CC Switch，原生插件走官方管理器，独立应用自己管理，同名技能只交给一个管理器。

请区分来源核查、已安装、客户端发现和实际任务通过；多个客户端分别记录，不静默删掉我要求的客户端。不要把读取清单当成安装授权，也不要重复询问本会话已经明确批准的操作。不要索要公开贴出的凭据、公司原件或私人路径。

默认交付易读的推荐与使用卡，不要求我学 JSON 或用自研脚本。只有我明确需要技术清单时才补 profile；真实配置与结果保留在私有位置。
```

## 不想访谈，也可以直接选一件事

```text
我只想把一页原创 Markdown 笔记排成可读的中文 PDF。
请先查看我当前客户端已有的办公能力，用三段演示文字给我一个使用例子。
告诉我在哪里打开、会生成什么文件、怎样检查字体和分页。
如果已有能力足够，这次就用它，不增加独立应用。
```

```text
我想了解怎样用 AI 检查自己的个人网站，已有浏览器和代码编辑器。
请先区分页面阅读、浏览器交互、软件文档查询各要用什么，
对照本仓库推荐给我一套最小选择，并明确我这台机器哪些能力还没确认。
先给公开页面短例，不部署网站或连接服务器。
```

工具准备好后，可在 [任务目录](../catalog/README.md) 或 [使用卡索引](../recipes/README.md) 找入口。想复用组合请求，查看 [办公](../playbooks/reports-and-office.md)、[代码阅读](../playbooks/embedded-code-context.md)、[研究与小网站](../playbooks/research-and-small-sites.md)。[历史 profiles](../profiles/examples/README.md) 只供需要结构化辅助资料的人使用。
