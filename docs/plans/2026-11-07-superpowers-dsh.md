# DSH Superpowers 执行计划

日期：2026-11-07。依据 [设计与自审](../design/2026-11-07-superpowers-dsh.md)，按用户授权连续执行。

1. 社区候选对照：固定源码与发布包分别评审，记录许可、Windows、工具映射和首轮触发的经验。
2. 私有验证：创建独立演示 profile，先跑无插件基线，再用已评审固定来源加载插件；运行上游测试与真实模型用例。
3. 原生安装：核查本机使用入口与现有状态，备份目标 profile，以 DSH 原生管理器安装完整 bundle；确认来源及运行时注册。
4. 验收：新会话中检查技能调用、需求澄清、调试、TDD 和子代理；区分本机测试结果与社区报告。
5. 文档：更新中文使用卡、目录来源、首页入口与验收记录。原始日志、真实配置、下载和备份只放 `.local/`。
6. 独立评审与发布：检查来源/隐私/引用，运行相关校验；完成后提交并推送用户仓库，确认远端提交一致。

不新增与文档内容一一镜像的测试。若只复用现成插件，不自造适配实现；使用插件原有测试与真实 DSH 入口检查。
