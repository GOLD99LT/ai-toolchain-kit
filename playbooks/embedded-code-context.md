# 代码阅读任务：从短源码问题开始

只提供教学请求，使用仓库中的 [合成样例](../examples/stm32-context/README.md)。本卡不继续分析真实固件，不编译、烧录或操作硬件。示例路径可替换为后来明确允许处理的小项目。

## 直接阅读并说明依据

```text
只读 examples/stm32-context 中的源码和配置，先不读取 EXPECTED.md、expected.json 或含答案的说明文件。
说明入口、初始化顺序，以及一条 IRQ 到回调的路径。
每个结论附文件名和符号；区分直接调用、受宏影响的路径与仅凭源码不能确定的行为。
不要修改代码、安装工具、编译或操作硬件。结果直接回复在对话中。
```

自己核对一条路径是否能回到源文件；同名 static、弱符号和条件编译不要混成一个无条件调用图。

## 需要带到另一个对话时打包

使用 [Repomix](../recipes/repomix.md) 的项目内入口。下列请求会生成私有演示材料，命令选项已对照 1.18.1 本地帮助：

```text
从本仓库根目录创建 .local/repomix-demo/（如不存在），运行：
node runtime/repomix/node_modules/repomix/bin/repomix.cjs examples/stm32-context --include "**/*.c,**/*.h" --output .local/repomix-demo/code.xml
列出实际纳入的文件，检查中文注释和函数体是否保留。
不要加入答案文件，也不要把打包成功称为代码理解或编译成功。
```

把生成的材料交给另一个客户端时可以复制：

```text
请读取我提供的 code.xml，只根据包内源码解释 IRQ 到回调的路径，附原文件名和符号。
这个包只选了 C/H 文件，缺少编译配置时请说明不确定性。
区分两个文件中的同名 static，不读取其他答案文件。只回答，不修改工程。
```

默认 XML 风格输出用于阅读，不保证可直接作为严格 XML 解析。历史 UTF-8 材料保留通过也不证明旧 GBK 工程可用；发现缺文件先看选择规则和编码。

## 要图或符号导航时的请求

```text
我需要看懂这个小项目的模块关系。请先比较直接阅读、Understand-Anything 图形导览、Serena 符号查询分别能增加什么。
我的编译参数情况是：<已齐备或尚未齐备>。
只给适合我的选择和一条短演示建议；候选尚未安装就明确写出，不启动安装，也不把补完整 GCC 环境作为看卡片的前置要求。
```

[Understand-Anything](../recipes/understand-anything.md) 适合需要图形导览时考虑；[Serena](../recipes/serena.md) 在编译参数满足后考虑；[GitNexus](../recipes/gitnexus.md) 暂缓。普通小样例不要求先做完整账户恢复演练。

输出是对话解释、可选的阅读材料或未来工具生成的图。分别记录材料完整性和各客户端回答；真实编译、硬件与恢复没有做就写未执行，不算没有测量依据的提效百分比。
