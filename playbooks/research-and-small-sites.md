# 资料研究与小网站：按需要复制请求

偶发查资料先用当前搜索/浏览能力；交互页面用 [Playwright MCP](../recipes/playwright-mcp.md)，软件库文档用 [Context7](../recipes/context7.md)。两项直接服务短例已成功，agent 对话内结果待确认；在现有客户端重开或新会话使用即可，无需为验证另建 DSH headless profile。

## 比较公开资料

```text
比较我随后提供的3个公开产品页面，只看接口、供电范围和尺寸。
先说明实际读取到了哪些页面；需要动态交互时使用已配置的 Playwright MCP。
输出“产品—原值与单位—来源URL—查阅日期—未知项”表。
相互冲突的规格保留两条来源，打不开或缺字段就写未知，不凭搜索摘要补结论。
```

抽查一个数字和一个未知项是否能回到原页面。这里交付来源表，不自动订阅、采集整站或操作购买表单。

## 查询项目使用的库版本

```text
使用 Context7 查询 <库名> <实际版本> 的 <具体用法>，先确认库与版本是否匹配。
给一个最小代码示例，标出文档依据；检索不到该版本就说明缺口。
只回答问题，不安装依赖、不修改项目、不把检索成功说成代码已运行。
```

检查例子中的一个函数签名与来源是否一致。Context7 本次走 remote 无密钥路线，查询会发送给外部服务；不要贴入密钥或不应外发的代码。

## 检查自己已经启动的网页

```text
使用已配置的 Playwright MCP 打开 <我的本地网页地址>。
检查首页导航、文章链接和手机宽度下的横向溢出，报告问题与复现步骤。
如果浏览器或网页打不开，给准确失败原因；没有打开的页面不标通过。
先只检查，不提交表单、不修改代码、不部署网站。
```

本地地址必须替换成已能打开的实际页面。结果应包含实际观察与来源，若保存截图则给出真实位置，不以 MCP 连接成功代替页面检查。

## 想做网站，先选已有材料

```text
我想做一个个人介绍页和文章列表，没有登录、数据库或交易。
请根据现有研究比较 AstroWind 模板配合当前助手，与 bolt.diy 可视化工作台。
说明入口、我需要准备的原创内容、模型与托管费用类别，以及各自维护工作。
只给选择和一个演示任务，不创建网站、不连接 VPS。
```

[AstroWind](../recipes/astrowind.md)、[bolt.diy](../recipes/bolt-diy.md) 都是候选。重复批量抽取时再看 [Crawl4AI](../recipes/crawl4ai.md) 或 [Firecrawl](../recipes/firecrawl.md)；要长期运维多个服务时才看 [Coolify](../recipes/coolify.md) 或 [Dokploy](../recipes/dokploy.md)。这些条件不由一次资料查询自动触发。

表格、笔记和截图保存在自己的私有项目目录；公开素材可阅读不代表可再分发。本卡请求是使用教学，网站与 VPS 是否真正建立、上线，要有后来单独任务的实际记录。
