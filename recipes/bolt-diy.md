# bolt.diy：浏览器里的 AI 搭站工作台

在同一界面中聊天生成、预览、编辑和导出网站代码。

**状态（2026-11-05）**：候选，尚未安装；2026-11-04 观察 v1.0.1，Windows 启动和代码导出尚未验证。 最终状态看 [本轮配置与验证记录](../docs/validation/2026-11-05-toolbox-rollout.md)。

## 何时用

喜欢边聊天边看页面预览、希望手动调整代码时考虑。现有 Codex 加模板已经够用时，可继续现有方式，避免额外维护工作台。

## 入口与输入

选用后按官方支持方式启动，在浏览器打开工作台；实际地址以启动输出为准，不猜端口。导出的代码可交给 Codex/DSH 阅读，不等于原生插件接入。

准备网站目的、页面内容和小范围交互；需要所选版本规定的 Node/pnpm、支持的浏览器/WebContainers，以及模型 API 或本地端点。Docker 是可选路线。

## 两个可复制例子

以下是使用请求，示例本身不表示已经执行。尖括号内容请换成自己的实际输入；候选工具需先完成选用与配置。

**例一：制作原创展示页**

```text
制作一个“周末读书小组”的单页演示，包含介绍、三本占位书目和联系说明。使用原创文字与纯色占位图，无登录、支付或真实提交功能。请在预览中展示，保留可编辑代码。
```

**例二：修改后导出**

```text
把当前演示页改成适合手机阅读的单栏布局，检查导航和文字溢出。请导出完整代码，并根据实际 package.json 说明如何在独立项目中构建；区分已经验证和还没验证的步骤，不自动上线。
```

## 输出与判断

工作台预览、可编辑项目与导出代码；下载/导出位置由产品实际操作确定。导出后应能在自己的项目中继续维护。

改一处文案看预览是否更新，再检查导出内容和独立构建。只有聊天回答或界面截图不能证明代码完整可用。

## 管理、更新与停用

工作台及模型连接由项目官方方式管理，网站代码由导出的项目负责。更新前备份项目和私有设置，按选定发布核对资产；停用时停止本地进程/服务，卸载前导出作品。CC Switch 不维护其依赖。

## 费用与数据

代码研究快照为 MIT，WebContainers 另有条款。模型 API、图片服务或本地推理资源另计；现有聊天订阅不保证有 API 额度，提示与代码会交给所配置模型。

## 常见问题

- **Docker 镜像或发布文件找不到？** 历史有启动与发布资产报告，核对所选发布真实存在的路线，不猜镜像 tag。
- **预览能看但导出构建失败？** 检查导出文件、依赖和实际脚本，保留失败记录，不报上线成功。
