# GitNexus：暂缓的代码图谱候选

提供调用图、路径与影响查询，适合在条件满足后比较代码导航体验。

**状态（2026-11-05）**：暂缓候选，未安装。2026-11-04 观察 v1.6.12；工作用途许可和 Windows 索引问题未解决，不列入公司默认工具。 最终状态看 [本轮配置与验证记录](../docs/validation/2026-11-05-toolbox-rollout.md)。

## 何时用

确实需要图谱查询且使用场景符合许可时再考虑。当前可先用直接阅读、Repomix，或了解 Understand-Anything；不要仅凭图形好看更换流程。

## 入口与输入

候选选用后从项目官方说明选择 CLI、MCP 或图浏览器的实际路线；本卡不提供未核实启动参数，Codex/DSH 原生接入未确认。

准备允许使用的演示仓库、已知定义/调用关系和使用用途。Node、平台依赖及索引后端按所选发布核对，不能假定任意 Windows 环境可用。

## 两个可复制例子

以下是使用请求，示例本身不表示已经执行。尖括号内容请换成自己的实际输入；候选工具需先完成选用与配置。

**例一：先判断是否适合**

```text
根据本仓库 GitNexus 研究记录，帮我判断它是否适合 <个人非商业学习或公司工作> 的代码导航。分别列用途许可、Windows 支持和实际索引验证的缺口；只给选择建议，不安装、不把未确认项写成通过。
```

**例二：已具备条件时查调用路径**

```text
在 GitNexus 已配置且用途条件确认后，对 <合成演示目录> 查询 <入口函数> 到 <目标函数> 的路径。逐个对照原文件，列出缺节点和无法确认的函数指针关系，不修改源代码。
```

## 输出与判断

例一是取舍与缺口说明；例二才是索引查询结果或图浏览器视图。索引和导出文件放自己的项目私有目录。

至少核对一个应存在的函数节点和调用关系；命令成功但缺节点仍是结果不完整。没有执行例二时只能报告建议，不能标任务通过。

## 管理、更新与停用

选用后由该项目官方方式管理程序及索引；若接入 MCP，配置由 CC Switch 负责。更新先核对所选版本的许可与问题修复，再试原样例；停用接入后停止对应进程，删除索引不应删除源码。

## 费用与数据

研究快照许可为 PolyForm Noncommercial 1.0.0，不能当作无用途限制的免费工具。模型/服务路线若需额外额度应另计；本地索引与发送到模型的代码范围须分别确认。
