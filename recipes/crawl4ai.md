# Crawl4AI：反复抽取同类网页字段

按固定规则批量读取网页并提取字段，减少重复手工复制。

**状态（2026-11-05）**：候选，尚未安装；2026-11-04 观察 v0.9.5，Windows 浏览器运行与抽取效果待验证。 最终状态看 [本轮配置与验证记录](../docs/validation/2026-11-05-toolbox-rollout.md)。

## 何时用

同类公开网页经常需要提取相同字段时考虑。偶尔读几页先用现有浏览工具；它只能补充 BOM 资料，不能替代料号、数量和单位规则。

## 入口与输入

选用后按官方 Python 示例运行抽取任务，结果再交给助手整理。没有已验证的 Codex/DSH 原生接入；不要求常驻服务。

先准备 3–5 个允许访问的 URL、字段定义、缺值规则和输出目录。需要独立 Python 环境、Playwright 及匹配浏览器；语义抽取才另配模型。

## 两个可复制例子

以下是使用请求，示例本身不表示已经执行。尖括号内容请换成自己的实际输入；候选工具需先完成选用与配置。

**例一：抽取三个页面**

```text
在 Crawl4AI 已配置后，读取我提供的3个公开产品页面，抽取名称、接口、供电范围和来源 URL，优先使用正文或明确的页面规则。缺字段保留空值并说明，不自动调用模型，不安装新依赖。
```

**例二：检查长页和分页**

```text
用同一抽取规则处理 <公开长页URL> 与 <公开分页URL>，只处理我指定的页面。保存采集时间、原字段值和失败原因，重点核对末尾字段和分页遗漏，输出到我指定的私有目录。
```

## 输出与判断

按实际任务组织的 Markdown、JSON 或表格数据，保留 URL、采集时间与原值；这些是交给后续整理的材料。

对照一个普通页、一个缺字段页，抽查数字和单位，并检查长页末尾。访问失败保留失败；不把空值补成看似合理的参数。

## 管理、更新与停用

由独立 Python/浏览器环境负责人更新，按选定版本检查规则兼容；若有常驻服务，由同一负责人维护。停用即不再运行任务，卸载前保留自己的抽取规则和结果，确认环境是否共用。

## 费用与数据

研究快照为 Apache-2.0 主体并含额外署名条款。规则抽取可不调用 LLM，但占用本地运行资源；语义抽取与外部代理/服务按实际选择计费，网页内容可能传给配置模型。

## 常见问题

- **安装了却起不来浏览器？** 检查匹配浏览器和运行依赖，pip 成功不代表浏览器就绪。
- **动态内容为空或网站拒绝？** 先核查页面加载与访问条件，缩到单页查原因；不自动绕过访问控制。
