# Codex 原生办公：报告、PDF、PPT 与表格

把已提供的资料整理为可审阅的报告、可编辑演示和可核对的表格。

**状态（2026-11-05）**：Codex 已有 documents、pdf、presentations、spreadsheets 原生入口；DSH 等价入口与任务结果待确认，换机获取方式仍需核对。 最终状态看 [本轮配置与验证记录](../docs/validation/2026-11-05-toolbox-rollout.md)。

## 何时用

汇总测试资料、把 Markdown 排成中文 PDF、做汇报 PPT、检查 BOM 时先用现有办公能力。扫描表格读不准时再比较 Docling；需要独立可视化制稿界面时再看 Presenton。

## 入口与输入

在 Codex 对话中附上允许处理的文件，直接说输出格式；需要时明确“使用 documents / pdf / presentations / spreadsheets”。插件由 Codex 原生入口管理。

准备资料、目标读者、篇幅或页数、允许使用的模板、BOM 合并规则和输出位置。第一次可用自己编写的三行数据或一页笔记。

## 两个可复制例子

以下是使用请求，示例本身不表示已经执行。尖括号内容请换成自己的实际输入；候选工具需先完成选用与配置。

**例一：测试汇总到 PDF**

```text
使用现有办公能力，把下面的演示测试记录整理成一页中文报告，并交付 Markdown 和 PDF：样机A启动测试10次，成功9次；一次失败原因未明。请列结果、限制和下一步，逐页检查中文字体和表格，输出到 .local/office-demo/。这是合成数据。
```

**例二：BOM 差异表**

```text
使用表格能力比较两个合成 BOM：V1 有 R-10K，数量10，单位个；C-1U，数量5，单位个。V2 有 R-10K，数量12，单位个；C-1U，数量1，单位包。请生成 XLSX，保留原数据、数量变化和单位冲突；未知包装换算不计算。输出到 .local/office-demo/。
```

## 输出与判断

按请求交付 Markdown、DOCX、PDF、PPTX 或 XLSX，并给出实际生成位置和预览；默认由任务指定私有输出目录。

PDF 逐页看中文、分页与表格；PPT 用目标软件检查可编辑性；BOM 核对原行、单位、公式和总量。能下载文件不等于内容正确，缺模板时不能写公司格式已通过。

## 管理、更新与停用

启用、更新和停用使用 Codex 原生插件管理入口；不把插件缓存中的技能复制到 CC Switch 或 Skills CLI。更新后用同一小文件试一次。卸载插件前保留自己的成果文件；新机器需确认官方获取途径和运行依赖。

## 费用与数据

按当前 Codex/模型及插件实际使用条件计费，不假设额外 API 免费。文件可能交由宿主运行环境或模型处理，具体位置以当次工具为准；公司模板和原件留私有目录。

## 常见问题

- **中文乱码或表格截断？** 让助手检查字体及渲染预览，再重新导出。
- **DSH 能否直接用同一套？** 当前没有等价验证；可阅读已导出的产物不代表有原生生成能力。
