# Serena：查代码定义与引用

通过语言服务器查询符号定义和引用，帮助长期阅读 C/C++ 等代码项目。

**状态（2026-11-05）**：候选，尚未安装或验证 Codex/DSH 接入；2026-11-04 观察版本 v2.1.0，不是安装锁。 最终状态看 [本轮配置与验证记录](../docs/validation/2026-11-05-toolbox-rollout.md)。

## 何时用

频繁跨文件找定义、查调用者，而且已有可靠编译参数时考虑。Keil 到 GCC 的环境尚未就绪时，先直接读代码，不把完善整个工具链变成工具箱入门条件。

## 入口与输入

选用后按官方方式建立 Serena 运行环境；MCP 连接优先由 CC Switch 管理，再在目标客户端对话中请求符号查询。运行环境与 MCP 配置分别有明确负责人。

C/C++ 需要 clangd、有效的 include/宏/目标参数和 compile_commands.json；Python/uv 版本按选定发布确认。提供具体符号和允许读取的项目范围。

## 两个可复制例子

以下是使用请求，示例本身不表示已经执行。尖括号内容请换成自己的实际输入；候选工具需先完成选用与配置。

**例一：找一个函数**

```text
使用已配置的 Serena，在 <演示项目> 查询 <函数名> 的定义和跨文件引用。先确认索引已经完成，返回文件、位置和引用类型；查询失败或没有足够编译参数时如实说明，只读不改代码。
```

**例二：区分同名符号**

```text
使用 Serena 检查 <演示项目> 中两个同名 static 函数，分别列出所属文件和引用。说明当前宏配置对结果的影响；不要把不同文件的同名函数合并，也不要把空查询当作没有调用者。
```

## 输出与判断

对话中的符号位置、引用清单和源码解释；工具缓存/索引的位置由实际运行配置确认，保留在项目私有范围。

用一个定义和一个已知跨文件引用作短演示，并对照源码；有编译条件时说明所用配置。CLI 启动或索引建立不等于查询准确。

## 管理、更新与停用

Serena 程序与语言服务器按各自官方固定来源更新；CC Switch 只管理其 MCP 条目，不接管 Python 环境。更新后检查同一引用；停用 MCP 后再停止服务，卸载前确认没有其他项目共用环境，索引按工具说明清理。

## 费用与数据

研究快照：应用 GPL-3.0-or-later，SolidLSP 为 MIT。语言服务器本地索引消耗资源；智能体解释通常消耗模型额度，工具返回的源码片段可能进入模型上下文。

## 常见问题

- **引用结果为空？** 先等索引完成，再查 clangd、编译数据库和宏/include 配置。
- **没有 compile_commands.json？** 保留该能力待配，先用源码阅读；不要伪造编译参数来制造成功。
