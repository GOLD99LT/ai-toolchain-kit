# Presenton：在可视化界面制作 PPT

通过独立制稿界面生成、编辑演示文稿，适合希望边看版式边修改的人。

**状态（2026-11-05）**：候选，尚未安装；2026-11-04 观察 v0.9.12-beta，公司模板和 Windows 导出效果待验证。 最终状态看 [本轮配置与验证记录](../docs/validation/2026-11-05-toolbox-rollout.md)。

## 何时用

经常做汇报且希望有专门的可视化制稿界面时比较。已有 Codex 办公能力够用时先复用；公司母版导入/重建效果不能预先保证。

## 入口与输入

选用后从官方支持的桌面或独立应用入口打开。当前没有确认 Codex/DSH 原生集成；模型、图片服务在产品自身设置中配置。

准备一页提纲、听众、页数、可用图文与输出目录；若试模板，提供允许使用的演示 PPTX。模型 API 或本地模型端点需真实可用，桌面试用不默认要求 Docker。

## 两个可复制例子

以下是使用请求，示例本身不表示已经执行。尖括号内容请换成自己的实际输入；候选工具需先完成选用与配置。

**例一：五页演示汇报**

```text
生成5页中文演示，主题为“个人阅读计划”：目标、每周安排、书单分类、记录方式、下月检查点。每页最多3个要点，不使用真实公司资料。生成后让我在编辑界面调整，再导出可编辑 PPTX。
```

**例二：比较演示模板**

```text
用我提供的原创演示 PPTX 作为样式参考，把同一份阅读计划做成5页。请尽量匹配字体、配色与页脚，列出无法保留的母版效果；导出后说明哪些元素可以继续编辑，不把预览正常当成导出正常。
```

## 输出与判断

产品中的可编辑演示与实际导出的 PPTX；导出位置由用户在产品中选择。若另导出 PDF，也要单独查看。

用目标办公软件打开 PPTX，检查文本可编辑、中文字体、图表、对齐和页脚，再核对逐页预览。文件未导出成功就记录失败。

## 管理、更新与停用

程序及模型连接由 Presenton 官方入口管理，CC Switch/Skills CLI 不维护其项目。更新前保留演示源文件与私有配置，更新后导出同一小稿；停用时退出应用/停止服务，卸载前导出自有作品。

## 费用与数据

代码研究快照为 Apache-2.0；模型 API、图片服务、托管功能按实际选择计费，聊天订阅不等于 API 额度。提纲、模板和图片可能发送到所配置服务。

## 常见问题

- **预览正常但 PPTX 导不出？** 记录版本和脱敏错误，检查所用导出路线；历史 Windows 版本有此类报告，不能推定当前已修复。
- **能完整保留公司母版吗？** 不能承诺，先用允许处理的模板小样检查。
